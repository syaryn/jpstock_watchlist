# jpstock-watchlist

証券会社からダウンロードしたスクリーニングCSV（Shift-JIS / CP932）を解析し、独自の多角的スコアリング（最大350点）でソート・可視化する、PEP8準拠・型安全なPythonツールです。mise / uv / ruff / ty / lefthook で品質を担保します。

## 主な機能
- **証券会社CSV分析**:
  - `input/` フォルダ内の最新CSV（または指定CSV）を自動解析。
  - 実績ROE、ROIC、予想配当利回り、予想PEGレシオ、3年配当成長率、予想PER、PBR、52週株価相対水準、配当性向、総還元性向など多角的な指標を網羅して投資スコアを算出。
- **JPX400 構成銘柄の自動判定**:
  - `input/screener_result.csv` を参照し、JPX日経インデックス400採用銘柄に「〇」フラグを付与。
- **NISA成長投資枠（240万円）ラインの自動挿入**:
  - スコア順に降順ソートし、単元株（100株）ずつの累計買付額が **240万円** に達するラインに自動で区切り線を挿入。
- **Rich ターミナル表示 & Markdown レポート自動出力**:
  - ターミナル上に視認性の高いテーブルを描画。
  - `output/csv_YYYYMMDD.md` へJST（日本標準時）日付ベースのMarkdownレポートを自動出力。

## 必要ツール
- [mise](https://mise.jdx.dev/)（Pythonや開発ツールの管理）
- Python 3.14+（miseがインストール）

## セットアップ
1. mise をインストール（未導入の場合）
   ```bash
   curl https://mise.run | sh
   ```
2. 開発ツールをインストール
   ```bash
   mise install
   ```
3. 依存関係をインストール（uvが自動でvenv作成）
   ```bash
   uv sync
   ```
4. Gitフックを設定
   ```bash
   lefthook install
   ```

## 使い方

### スクリーニングCSVの解析
```bash
# input/ フォルダ内の最新CSVファイルを自動スキャンして処理する場合:
mise run analyze
# または: uv run python main.py

# CSVファイルを個別に指定して処理する場合:
uv run python main.py --input input/screening_20260620.csv
```

実行するとCSVデータを解析し、ターミナルに結果テーブルを表示した上で、`output/csv_YYYYMMDD.md` へMarkdown表を出力します。

### 出力カラム
- コード / 会社名 / 市場 / JPX400 / 業種 / 直近終値 / 時価総額 / 実績ROE / ROIC / 予想配当利回り / 予想PEGレシオ / 3年配当成長率 / 予想PER / PBR / 52週株価相対水準 / 配当性向 / 総還元性向 / スコア (降順ソート)

## スコアリング基準（最大350点）
本システムでは、企業の**収益性・成長性（ROE、ROIC、配当成長、PEGレシオ）を重視**した設計となっています。
スコアは **絶対評価スコア（ベーススコア：最大160点）**、他銘柄との相対比較による **相対評価スコア（最大160点）**、および **時価総額ボーナス（最大30点）** を合算して算出されます。

### A. 絶対評価スコア（ベーススコア：最大160点）
主要10指標について、それぞれ設定された閾値に基づき評価します。

| 指標 | 条件と配点 | 最大点 / 最小点 |
| :--- | :--- | :--- |
| **実績ROE** | $\ge 20\%$ : **+30**<br>$\ge 15\%$ : **+25**<br>$\ge 12\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 5\%$ : **+10**<br>$\le -10\%$ : **-20**<br>$< 0\%$ : **-10** | +30 / -20 |
| **3年配当成長率** | $\ge 50\%$ : **+25**<br>$\ge 30\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 0\%$ : **+5**<br>$\le -30\%$ : **-20**<br>$< 0\%$ : **-10** | +25 / -20 |
| **ROIC** | $\ge 15\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 7\%$ : **+10**<br>$\ge 4\%$ : **+5**<br>$\le -5\%$ : **-15**<br>$< 0\%$ : **-10** | +20 / -15 |
| **予想PEGレシオ** | $\le 0.5$ : **+20**<br>$\le 1.0$ : **+15**<br>$\le 1.5$ : **+10**<br>$\le 2.0$ : **+5**<br>$> 2.0$ : **-10**<br>$\le 0$ : **-15** | +20 / -15 |
| **予想配当利回り** | $\ge 4.5\%$ : **+15**<br>$\ge 3.5\%$ : **+12**<br>$\ge 2.5\%$ : **+8**<br>$\ge 1.5\%$ : **+4** | +15 / 0 |
| **予想PER** | $\le 10$ : **+10**<br>$\le 12$ : **+8**<br>$\le 15$ : **+6**<br>$\le 20$ : **+4**<br>$\le 25$ : **0**<br>$\le 40$ : **-3**<br>$\le 60$ : **-8**<br>$> 60$ : **-15**<br>欠損/負数: **-8**（※1） | +10 / -15 |
| **PBR** | $\le 0.8$ : **+10**<br>$\le 1.0$ : **+8**<br>$\le 1.3$ : **+6**<br>$\le 1.6$ : **+4**<br>$\le 2.0$ : **0**<br>$\le 4.0$ : **-3**<br>$\le 8.0$ : **-8**<br>$> 8.0$ : **-15**<br>欠損/負数: **-8** | +10 / -15 |
| **52週株価相対水準** | $\le 30\%$ : **+10**<br>$\le 50\%$ : **+5**<br>$\le 5\%$ : **-10** | +10 / -10 |
| **総還元性向** | $\ge 80\%$ : **+10**<br>$\ge 50\%$ : **+8**<br>$\ge 30\%$ : **+5**<br>$\ge 15\%$ : **+2**<br>$< 0\%$ : **-5** | +10 / -5 |
| **配当性向** | $30\% \le$ 配当性向 $\le 60\%$ : **+10**<br>$20\% \le$ 配当性向 $< 30\%$ または $60\% <$ 配当性向 $\le 80\%$ : **+6**<br>$15\% \le$ 配当性向 $< 20\%$ または $80\% <$ 配当性向 $< 100\%$ : **+3**<br>$\ge 100\%$ : **-5**<br>$< 0\%$ : **-15** | +10 / -15 |

* ※1 予想PERが欠損または負数であっても、**実績ROEがプラス（黒字）**であればペナルティは適用されず **0点** となります（実績ROEがマイナスまたは0以下の場合は **-8点**）。

### B. 相対評価スコア（最大160点）
有効な数値を持つ銘柄群の中で、各指標のパーセンタイル順位に応じて按分計算を行います。
* **実績ROE (最大30点)**: 高いほど高得点 (正数値のみ対象)
* **3年配当成長率 (最大25点)**: 高いほど高得点 (正数値のみ対象)
* **ROIC (最大20点)**: 高いほど高得点 (正数値のみ対象)
* **予想PEGレシオ (最大20点)**: 低いほど高得点 (正数値のみ対象)
* **予想配当利回り (最大15点)**: 高いほど高得点
* **予想PER (最大10点)**: 低いほど高得点 (正数値のみ対象)
* **PBR (最大10点)**: 低いほど高得点 (正数値のみ対象)
* **52週株価相対水準 (最大10点)**: 安値圏ほど高得点
* **総還元性向 (最大10点)**: 高いほど高得点 (100%上限)
* **配当性向 (最大10点)**: 30%〜60%の範囲は **10点**。30%未満または60%超過は乖離に応じて減点。

### C. 時価総額ボーナス（最大30点）
* **1兆円以上**: **+30 点**
* **3000億円以上 1兆円未満**: **+20 点**
* **1000億円以上 3000億円未満**: **+10 点**
* **1000億円未満**: 加点なし
