# jpstock-watchlist

日本株ウォッチリストをスコアリング付きで生成する、PEP8準拠・型安全なPythonプロジェクトです。mise/uv/ruff/ty/lefthook で品質を自動担保します。

## 主な機能
- **Yahoo Finance (yfinance) 連携モード**:
  - オンラインからリアルタイムに株価・財務データを取得し、ROE/EPS成長率/予想PER/PBR/配当利回りなどを用いて投資スコア（260点満点）を算出。
- **証券会社CSV (Shift-JIS) 分析モード**:
  - ダウンロードしたスクリーニングCSVからローカルでデータを解析。実績ROE/ROIC/PEGレシオ/PER・PBR想定レンジ/3年配当成長/総還元性向/目標株価乖離率などを含む12指標を網羅して投資スコア（210点満点）を算出。
- `output/` に日本語のMarkdown表を自動出力（yfinance版は `YYYYMMDD.md`、CSV版は `csv_YYYYMMDD.md`）
- スコア順に降順ソートし、100株ずつの累積購入額が **240万円** (NISA成長投資枠の上限) に達するラインに自動で区切り線を挿入
- Pydantic + ty による型安全なデータ処理
- Rich によるターミナル表の表示
- ruff / lefthook によるPEP8準拠と自動チェック

## 必要ツール
- [mise](https://mise.jdx.dev/)（Pythonや開発ツールの管理）
- Python 3.13+（miseがインストール）

## セットアップ
1. mise をインストール（未導入の場合）
   ```bash
   curl https://mise.run | sh
   ```
2. 開発ツールをインストール
   ```bash
   mise install
   ```
3. 依存関係をインストール（uvが自動でvenv作成）
   ```bash
   uv sync
   ```
4. Gitフックを設定
   ```bash
   lefthook install
   ```
5. 仮想環境を有効化
   ```bash
   source .venv/bin/activate
   ```
6. 銘柄を設定
   ```bash
   cp .env.example .env
   # 例: TICKERS=7203.T,6861.T,8035.T
   ```

## 使い方

### 1. Yahoo Finance 連携モード (オンライン取得)
```bash
mise run watch
# または直接実行: uv run python main.py
```
実行すると環境変数 `TICKERS` の銘柄を取得し、スコア計算後に `output/YYYYMMDD.md` へMarkdown表を出力します。

### 2. 証券会社CSV 分析モード (ローカルCSV解析)
```bash
# input/ フォルダ内の最新CSVファイルを自動スキャンして処理する場合:
mise run csv

# CSVファイルを個別に指定して処理する場合:
mise run csv -- --input input/screening_20260620.csv
```
実行するとCSVデータを解析し、スコア計算後に `output/csv_YYYYMMDD.md` へMarkdown表を出力します。

### 出力カラム
- **yfinance版**: ティッカー / 銘柄 / 現在値 / 前日比% / ROE / EPS成長 / 予想PER / PBR / 配当% / 5年騰落 / 時価総額 / スコア (降順ソート)
- **CSV版**: コード / 会社名 / 市場 / 業種 / 直近終値 / 時価総額 / 実績ROE / ROIC / 予想配当利回り / 予想PEGレシオ / 3年配当成長率 / PER想定レンジ位置(σ) / PBR想定レンジ位置(σ) / 52週株価相対水準 / 総還元性向 / 目標株価乖離率 / スコア (降順ソート)

### 1. オンライン版スコアリング基準（最大260点）
本システムでは、**絶対評価スコア（ベーススコア：最大125点）**、他銘柄との比較による**相対評価スコア（最大125点）**、および**時価総額ボーナス（最大10点）**を合算して最終スコアを算出します。

また、データの異常値や欠損を検知した場合、その項目は全銘柄のスコア計算から自動的に**グローバル除外**されます。

#### A. 絶対評価スコア（ベーススコア：最大125点）
各指標のしきい値に基づき、加点および減点（ペナルティ）を行います。

| 指標 | 条件と配点 | 最大点 / 最小点 |
| :--- | :--- | :--- |
| **ROE** | $\ge 20\%$ : **+30**<br>$\ge 15\%$ : **+25**<br>$\ge 12\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 5\%$ : **+10**<br>$\le -10\%$ : **-20**<br>$< 0\%$ : **-10** | +30 / -20 |
| **EPS成長率** | $\ge 50\%$ : **+25**<br>$\ge 30\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 0\%$ : **+5**<br>$\le -30\%$ : **-20**<br>$< 0\%$ : **-10** | +25 / -20 |
| **予想PER** | $\le 10$ : **+20**<br>$\le 12$ : **+15**<br>$\le 15$ : **+10**<br>$\le 20$ : **+5**<br>$\le 25$ : **0**<br>$\le 40$ : **-5**<br>$\le 60$ : **-15**<br>$> 60$ : **-25**<br>欠損/負数: **-15**（※1） | +20 / -25 |
| **PBR** | $\le 0.8$ : **+15**<br>$\le 1.0$ : **+12**<br>$\le 1.3$ : **+8**<br>$\le 1.6$ : **+4**<br>$\le 2.0$ : **0**<br>$\le 4.0$ : **-5**<br>$\le 8.0$ : **-10**<br>$> 8.0$ : **-20**<br>欠損/負数: **-10** | +15 / -20 |
| **配当利回り** | $\ge 4.5\%$ : **+15**<br>$\ge 3.5\%$ : **+12**<br>$\ge 2.5\%$ : **+8**<br>$\ge 1.5\%$ : **+4** | +15 / 0 |
| **5年騰落率** | $\ge 100\%$ : **+10**<br>$\ge 50\%$ : **+5**<br>$\le -100\%$ : **-10**（※2）<br>$\le -50\%$ : **-5**（※2） | +10 / -10 |
| **52週高値下落率** | $\ge 30\%$ : **+10**<br>$\ge 20\%$ : **+7**<br>$\ge 10\%$ : **+4**<br>$\ge 50\%$ : **-15**<br>$\ge 80\%$ : **-30** | +10 / -30 |

* ※1 予想PERが欠損または負数であっても、**ROEがプラス（黒字）**であれば減点ペナルティは適用されず **0点** となります。
* ※2 新規上場などヒストリカルデータが短い銘柄（取引日数が500日未満）は、5年騰落率のマイナス評価（減点）は適用されません（0点）。

#### B. 相対評価スコア（最大125点）
対象銘柄群の中での相対的な良さに応じて、各項目を按分して加点します（四捨五入して整数化）。
* **ROE**: `(銘柄のROE / 最大ROE) * 30`
* **EPS成長**: `(銘柄のEPS成長 / 最大EPS成長) * 25`
* **予想PER**: `(最小PER / 銘柄のPER) * 20`
* **PBR**: `(最小PBR / 銘柄のPBR) * 15`
* **配当利回り**: `(銘柄の配当利回り / 最大配当利回り) * 15`
* **5年騰落率**: `(銘柄の5年騰落率 / 最大5年騰落率) * 10` (※新規上場かつマイナスの場合は0点)
* **52週高値下落率**: `max(0, (100 - 銘柄の下落率) / (100 - 最小下落率) * 10)` (下落率が小さいほど高得点)

#### C. 時価総額ボーナス（最大10点）
* **5兆円以上**: **+10 点**
* **1兆円以上 5兆円未満**: **+6 点**
* **1000億円以上 1兆円未満**: **+3 点**
* **1000億円未満**: 加点なし

---

### 2. CSV版スコアリング基準（最大330点）
CSV版では、**絶対評価スコア（ベーススコア：最大160点）**、他銘柄との比較による**相対評価スコア（最大160点）**、および**時価総額ボーナス（最大10点）**を合算して最終スコアを算出します。

本スコアリングは、割安性指標の配点を抑え、企業の**収益性・成長性（ROE、ROIC、配当成長、PEGレシオ）を重視**した設計となっています。

#### A. 絶対評価スコア（ベーススコア：最大160点）
CSVに存在する主要10指標について、それぞれ異なるウェイト（配点）で評価します。

| 指標 | 条件と配点 | 最大点 / 最小点 |
| :--- | :--- | :--- |
| **実績ROE** | $\ge 20\%$ : **+30**<br>$\ge 15\%$ : **+25**<br>$\ge 12\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 5\%$ : **+10**<br>$\le -10\%$ : **-20**<br>$< 0\%$ : **-10** | +30 / -20 |
| **3年配当成長率** | $\ge 50\%$ : **+25**<br>$\ge 30\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 0\%$ : **+5**<br>$\le -30\%$ : **-20**<br>$< 0\%$ : **-10** | +25 / -20 |
| **ROIC** | $\ge 15\%$ : **+20**<br>$\ge 10\%$ : **+15**<br>$\ge 7\%$ : **+10**<br>$\ge 4\%$ : **+5**<br>$\le -5\%$ : **-15**<br>$< 0\%$ : **-10** | +20 / -15 |
| **予想PEGレシオ** | $\le 0.5$ : **+20**<br>$\le 1.0$ : **+15**<br>$\le 1.5$ : **+10**<br>$\le 2.0$ : **+5**<br>$> 2.0$ : **-10**<br>$\le 0$ : **-15** | +20 / -15 |
| **予想配当利回り** | $\ge 4.5\%$ : **+15**<br>$\ge 3.5\%$ : **+12**<br>$\ge 2.5\%$ : **+8**<br>$\ge 1.5\%$ : **+4** | +15 / 0 |
| **予想PER** | $\le 10$ : **+10**<br>$\le 12$ : **+8**<br>$\le 15$ : **+6**<br>$\le 20$ : **+4**<br>$\le 25$ : **0**<br>$\le 40$ : **-3**<br>$\le 60$ : **-8**<br>$> 60$ : **-15**<br>欠損/負数: **-8**（※3） | +10 / -15 |
| **PBR** | $\le 0.8$ : **+10**<br>$\le 1.0$ : **+8**<br>$\le 1.3$ : **+6**<br>$\le 1.6$ : **+4**<br>$\le 2.0$ : **0**<br>$\le 4.0$ : **-3**<br>$\le 8.0$ : **-8**<br>$> 8.0$ : **-15**<br>欠損/負数: **-8** | +10 / -15 |
| **52週株価相対水準** | $\le 30\%$ : **+10**<br>$\le 50\%$ : **+5**<br>$\le 5\%$ : **-10** | +10 / -10 |
| **総還元性向** | $\ge 80\%$ : **+10**<br>$\ge 50\%$ : **+8**<br>$\ge 30\%$ : **+5**<br>$\ge 15\%$ : **+2**<br>$< 0\%$ : **-5** | +10 / -5 |
| **配当性向** | $30\% \le$ 配当性向 $< 60\%$ : **+10**<br>$20\% \le$ 配当性向 $< 30\%$ または $60\% \le$ 配当性向 $< 80\%$ : **+6**<br>$15\% \le$ 配当性向 $< 20\%$ または $80\% \le$ 配当性向 $< 100\%$ : **+3**<br>$\ge 100\%$ : **-5**<br>$< 0\%$ : **-15** | +10 / -15 |

* ※3 予想PERが欠損または負数であっても、**実績ROEがプラス（黒字）**であればペナルティは適用されず **0点** となります（実績ROEがマイナスまたは0以下の場合は **-8点**）。

#### B. 相対評価スコア（最大160点）
有効な数値を持つ銘柄群の中で、各指標の重みに応じて按分計算を行います。
* **実績ROE (最大30点)**: `(ROE / 最大ROE) * 30` (正数値のみ対象)
* **3年配当成長率 (最大25点)**: `(配当成長率 / 最大成長率) * 25` (正数値のみ対象)
* **ROIC (最大20点)**: `(ROIC / 最大ROIC) * 20` (正数値のみ対象)
* **予想PEGレシオ (最大20点)**: `(最小PEG / PEGレシオ) * 20` (正数値のみ対象)
* **予想配当利回り (最大15点)**: `(配当利回り / 最大利回り) * 15`
* **予想PER (最大10点)**: `(最小PER / 予想PER) * 10` (正数値のみ対象)
* **PBR (最大10点)**: `(最小PBR / PBR) * 10` (正数値のみ対象)
* **52週株価相対水準 (最大10点)**: `((100 - 相対水準) / 100) * 10` (安値圏ほど高得点)
* **総還元性向 (最大10点)**: `(総還元性向 / 最大性向) * 10` (※総還元性向は100%にキャップして計算)
* **配当性向 (最大10点)**: 30%〜60%の範囲は **10点**。30%未満は `(配当性向 / 30) * 10`。60%超過は `max(0, 10 - round((配当性向 - 60) / 40 * 10))` (過剰還元ほど減点)

#### C. 時価総額ボーナス（最大10点）
※CSVの時価総額単位（億円）に基づき算出します。
* **5兆円以上** ($\ge$ 50,000億円): **+10 点**
* **1兆円以上 5兆円未満** ($\ge$ 10,000億円): **+6 点**
* **1000億円以上 1兆円未満** ($\ge$ 1,000億円): **+3 点**
* **1000億円未満**: 加点なし
